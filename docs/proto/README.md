# WebGL2 三维原型（只做矩阵变换）

一个不依赖任何第三方库的单文件原型，用来验证「点位数据只做矩阵变换就能实时控视角」这个判断。

## 打开方式

```bat
:: 直接双击，或用 WebView2 / Chrome / Edge 打开
docs\proto\webgl3d.html
```

## 内含三组数据（`1` `2` `3` 切换）

| 键 | 数据 | 顶点 | 说明 |
|---|---|---|---|
| `1` | 点云 · 环形结 | 300,000 点 | 验证「点云只需一次上传 + 换矩阵」 |
| `2` | 折线 · 6 通道 × 20k | 120,000 顶点 | 对应 netlab 的 6 通道实时曲线 |
| `3` | 曲面 · 80×80 网格 | 6,400 顶点 / 12,482 面 | 验证网格：多一点三角索引，矩阵照样够 |

## 操作

`拖动` 旋转 · `滚轮` 缩放 · `Shift+拖动` 平移。

## 实测（WebView2，1727×1162）

| 模式 | fps |
|---|---|
| 点云 30 万 | **120** |
| 折线 6×20k | **120** |
| 曲面 80×80 | **109** |

对比：服务端 pyvista 每帧出 PNG 的路径是 26fps（瓶颈在 PNG 编码 30ms）。

## 关键点（也就是为什么能这么快）

- 顶点数据 **只上传一次**（`gl.STATIC_DRAW`），之后每帧只改一个 `uMVP` uniform（<0.05ms）；
- `gl_PointSize = uSize / p.w` 做透视衰减，`uSize` 按「世界半径 × 像素/世界」换算；
- 点用 `gl_PointCoord` 裁成圆形，曲面用解析法线做简单 lambert 着色。

## 这个原型做不到、但正式版要补的

- 坐标轴刻度/文字、色标（WebGL 里没有现成的，需要用 2D canvas 叠一层或 DOM）；
- 拾取（hover 读数、框选）——需要额外的离屏 id pass；
- 体渲染（voxels/等值面）——那是光线投射，不是「顶点 × 矩阵」；
- 数据来自服务端——现在三组数据都在 JS 里造，正式版要加 `/api/data` 二进制接口。
