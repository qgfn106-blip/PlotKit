## 这不是"随便画个爆炸"

取轴对称场（非定常 Burgers 涡）

```
u_r = -a(t)·r/2
u_θ = Γ/(2πr) · [1 - exp(-r²/(2δ(t)²))]
u_z = a(t)·z
```

代入不可压 Navier–Stokes 方程，`u_r/u_z` 是线性场（`ν∇²u = 0`），θ 方向动量方程恰好化简成

```
d(δ²)/dt = 2ν - a(t)·δ²
```

也就是说：**这一族是 NS 的精确解**，不是数值近似。再取应变率 `a(t) = a₀/(1-t/T)`（`a₀T = 1`），可积出闭式解

```
δ²(t) = (1 - t/T)·[δ₀² - 2νT·ln(1 - t/T)]
```

`t → T` 时 `δ² → 0⁺`，于是涡量峰值

```
ω_max = Γ/(2πδ²)  ~  1/(T - t)   →  ∞
```

**在有限时间内发散**，速度 `u_θ ~ δ^{-1/2}` 同时发散。这是"解本身在 T 时刻不再存在"的爆破，
不是数值格式失稳。

动画里的数字对得上：`t = 0` 时 `ω_max = 2.55`、`δ = 0.25`；`t = 0.97T` 时
`ω_max = 84.8`、`δ = 0.043`——`δ` 缩小 5.8 倍，`ω_max` 放大 33 倍，正好是 `δ⁻²` 的标度。

## 两点必须说明

1. **箭头长度是归一化的**。`a(t) → ∞` 时 `u_z = a·z` 会大到把画面甩穿，所以箭头统一长度、
   只表方向；真实的量级由颜色（涡量）和标题里的 `ω_max` 承担。
2. **它不构成千禧年问题的反例**。这一族在 z 方向无界（`u_z = a z`），总动能无穷；
   千禧年问题问的是**有限能量**初值是否整体光滑，那是另一件事。这里展示的是
   "NS 确实允许有限时间奇点"这一事实本身。

## 顺带修掉的库缺陷

写这个动画时发现两个真 bug，都已修 + 加测试：

- `scatter3d` 只能用 z 着色，加不了自定义标量场 → 现在支持 `data["scalar"]`（两个后端都支持）。
- `pyvista_backend` 的场景缓存只按 `(spec, 各数据集 version)` 做键，而**不同 DataStore 的
  version 都从 0 开始**，于是"每帧新建一个 Figure"时会把新数据判成同一场景、直接吐上一帧
  （GIF 60 帧全一样）。现在键里带上 store 身份，`test_pyvista_scene_cache_separates_stores` 兜底。
