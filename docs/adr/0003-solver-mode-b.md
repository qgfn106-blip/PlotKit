# ADR 0003：模式 B 用自研伪谱求解器，而不是引用外部数据

- 状态：已采纳（2026-11-01）
- 相关：`docs/NS_VORTEX.md` §17、`src/plotkit/ns/solver.py`

## 背景

任务书要求区分三种数据来源：A 数学构造复现、B 数值模拟、C 纯视觉演示。当时只有 A′（前导阶自相似解析场）。
参考工程 `cmccomb/navier-stokes-singularity-simulation` 用 AMReX/incflo 跑 128³ 嵌套网格，数据在浏览器里以 32³ float32 分块发布——但那套数据不在本机，也无法直接下载复用。

## 决策

用纯 NumPy 写一个 32³ 伪谱求解器（`src/plotkit/ns/solver.py`），作为模式 B 的数据源，通过 `source=solver` 接进所有 NS 接口。

## 理由

1. **可复现**：不依赖外部二进制数据，`python -m plotkit.ns.app --source solver` 就能在 15 s 内算出自己的场。
2. **够用**：32³ + 2/3 去混叠 + 谱投影，散度到 1e-17，涡量从 0 涨到 13.6，足以演示"涡量增强/轴向拉伸"的定性过程。
3. **不越界**：明确标注为 *finite surrogate*，不声称证明。

## 代价

- 32³ 的耗散偏大，峰值速度只有 0.44（参考工程 128³ 更高）；要看更细的核需要 64³（约 2 分钟）。
- 首次请求要等 ~15 s，所以接口设计成"首个请求返回 503 + 进度，前端轮询 `/api/ns/state`"。

## 备选方案与未采纳原因

| 方案 | 不采纳原因 |
| --- | --- |
| 直接下载参考工程的数据 | 数据不在公开可直连的位置，且体积/格式与本机浏览器协议不匹配 |
| 用 PhiFlow | 多一个重量级依赖（JAX/CUDA），与"纯 NumPy 可回退"的既有原则冲突 |
| 只做视觉演示（模式 C） | 用户明确要求"必须有真实物理数据支撑，禁止随机粒子/随机颜色伪造" |
