# ADR 0002 — 粒子在相似坐标下推进；箭头默认关、改为点选探针

- 状态：已采纳（2026-11-01）
- 相关：`src/plotkit/static/nsview.js`（`_advect`、`setArrows`）、`src/plotkit/static/ns.html`（`probeAt`、`applyXi`）

## 背景

用户反馈"粒子依然发散""箭头感觉完全无关""远端反而不发散"。

查证结论：
- "远端不发散"是**对的**——该自相似解的发散局限在核内（`u ~ q^{-A}`，q 随 r 迅速增大），远处本就光滑。问题在渲染把核外糊满，掩盖了核。
- 粒子"发散"的两个真因：①`τ → 0` 时 `|u| ~ τ^{-1/2-h}`，固定物理步长会让单步位移放大几十倍、越界被回收；②`t = 1.000` 时全部接口 400，画面卡在崩坏的一帧。
- 箭头"无关"是因为它画在最外层、长度近恒定，且与粒子表达同一件事（都在说"往里卷"），信息冗余。

## 决策

1. **粒子**：步长 `step ∝ τ^0.55`（自相似时间），并**按位移切子步**（单步 ≤ 2% 域长，最多 6 步）。
2. **相似坐标（ξ）**：开关打开时按 `L(τ)=τ^(1/2+h)` 拉近相机（限幅 0.35–4，防止钻进场内），让核保持屏幕尺度；**默认关闭**，默认视图展示"越缩越细"的真实收缩。
3. **箭头层默认关闭**；需要方向信息时用**点选探针**：点击画布取最近采样点，读出 `u_r/u_θ/u_z/|u|/Ω`。科学模式可临时打开稀疏箭头（7×20×6）。

## 后果

- 好处：默认画面干净；"发散"消失；方向信息从"看箭头"变成"读数值"，可核对。
- 代价：探针只覆盖箭头采样点（柱坐标稀疏网格），不是任意点的精确插值；密集箭头模式仍会遮挡。
- 遗留：τ < 0.01 区域数值上接近奇点，显示为高亮饱和而不是伪造结构（这是诚实的选择）。
