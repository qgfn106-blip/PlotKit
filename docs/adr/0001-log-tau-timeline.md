# ADR 0001 — 时间轴用对数 τ 刻度，末端不可达

- 状态：已采纳（2026-11-01）
- 相关：`src/plotkit/static/ns.html`（`tOfSlider`/`sliderOfT`）、`src/plotkit/server/ns_app.py`（`t ≥ 1` 一律 400）

## 背景

用户反馈"时间轴依然不对"。查证后有三个独立问题：

1. 滑条是**线性 t**，但物理上越接近奇异变化越快，线性刻度里前 90% 的行程几乎没有变化；
2. `t` 能被推到 `1.000`，而所有接口在 `t ≥ 1` 时返回 400 → 画面冻结在上一帧、时钟却继续走；
3. 时刻显示用 `τ = 1 − t`，但刻度没有 τ 标注，用户无法判断"还剩多少时间"。

## 决策

- 滑条位置 `u ∈ [0,1]` 映射 `τ = 0.005^u`（即 **对数 τ 刻度**），左端 `τ=1`（开始），右端 `τ=0.005`（奇异附近）。
- `t` 硬夹在 `[0, 0.995]`，**永远不产生 `t ≥ 1` 的请求**。
- 时钟区显示 `τ`（< 0.005 时显示 `<0.005`）、`t`、剩余时间，末端标"奇异不可达"。

## 后果

- 好处：越靠近奇异，滑条每一格的变化越明显；不再出现 400 冻结。
- 代价：滑条位置不再与 `t` 成正比，读数必须以 τ 为准；截图脚本要用 `--t` 而不是滑条比例。

## 备选（未采纳）

- 线性 t + 末端夹紧：简单，但"最后 10% 才是重点"的问题没解决。
- 以 τ 直接做刻度且从左到右递减：与用户阅读习惯相反。
