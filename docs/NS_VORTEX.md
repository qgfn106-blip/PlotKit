# 三维 NS 涡旋可视化（模式 A′：前导阶自相似解）

> 目标：把「Navier–Stokes 涡旋内旋、轴向拉伸、有限时间奇异性演化」做成 PlotKit 里一个**由真实场驱动**的三维可视化模块，而不是演示动画。
> 状态：2026-11-01 首版。渲染 98–120 fps，诊断与公式同屏，参数可实时调。

## 1. 数学来源与模式声明

- 论文：**Finite time blowup for Navier–Stokes**（2026-09-08，166 页，附 Lean 形式化仓库 `openai/NavierStokesAndEuler`）。§3.1 给出显式相似坐标，剖面 `E/U` 由 §4 隐式构造，**没有闭式解**。
- 本模块实现的是 **A′：前导阶相似场复现**。相似坐标与标度照搬论文：

```
τ = 1 − t
r = √(2qX)              z = q^{1/2−h} η
q = τ / (1 − η²)
u_θ = q^{−(1/2+h)} E(X, η)
u_z = q^{−(1/2+h)} U(X, η)
u_r = V₀(X) / r         （由不可压条件积出）
‖u‖_L∞ ~ τ^{−(1/2+h)}   ‖ω‖_L∞ ~ τ^{−1}
```

- 剖面（论文没有闭式，这里自选并**显式标注**）：

```
E = c∞ · sech²(η/η₀) · √X / (1 + (X/X₀)^{h+1})
U = c∞ · α · η · sech²(η/η₀) · √X / (1 + (X/X₀)^{h+1})
```

近轴 `E ≈ c∞√X`（轴上光滑，无 1/r 奇点），远场 `E ~ X^{−1/2−h}`（与论文尾部一致）；`U ∝ η` 保证 `z=0` 两侧轴向速度反向。
**不复现**：环带脉冲初始数据、光滑紧支外力（论文 §4 的构造工具），因此本模块**不声称**给出爆破解。

界面左下常驻标注：`Mode A-prime - Leading-order similarity field (not a verified blow-up solution)`。

## 4. 实测

场（`SimilarityParams()`，`h=0.005`）：

| 量 | τ=0.2 | τ=0.05 | τ=0.02 | τ=0.005 |
| --- | --- | --- | --- | --- |
| `u_max` | 0.840 | 1.834 | 2.909 | 5.818 |
| `ω_max` | 9.72 | 39.1 | 98.0 | 391.4 |
| 涡核半径 | 0.350 | 0.321 | 0.204 | 0.103 |

- 轴上角速度 `Ω = u_θ/r` 在 `r = 1e-4 … 1e-2` 恒定 → 刚体旋转核，无 1/r 奇点。
- 不可压残差 `‖∇·u‖/‖u‖`：t=0.2/0.5/0.9 → **2.5% / 2.3% / 2.1%**。
- 标度自洽：`u_max` 比值 6.9 ≈ 40^0.505，`ω_max` 比值 40.2 ≈ 40^1.0。

渲染（1280×820 窗口，2217×1372 canvas）：**98–120 fps**；粒子 24 000；体积 raymarch 每像素最多 220 步。

## 5. 已知限制

1. **不是爆破解**：只复现前导阶相似结构；论文的环带脉冲与紧支外力未实现，`h` 的严格区间是 `0<h<1/100`（界面放宽到 0.5 仅作视觉演示，`paper_compliant` 会标注）。
2. **剖面是自选的**：论文的 `E/U` 是隐式构造，没有闭式解，本模块用的是「sech² 核 + 幂律尾」近似族。
3. **视觉与参考视频有差距**：参考图那种「细亮丝 + 湍流状纹理」来自更陡的径向剖面与更多粒子；本场是光滑轴对称解，观感是「发光柱 + 螺旋粒子流」。
4. 网格列的散度残差（0.26）明显大于解析列（0.03），这是方位角离散误差，面板已如实展示。

## 12. 视觉调优（2026-11-01，对齐参考视频）

参考目标是「黑底 + 赤道同心环盘 + 橙色轴向柱 + 亮核」。要复现它，问题不在着色，而在**示踪粒子的撒点方式**：

| 现象 | 根因 | 做法 |
| --- | --- | --- |
| 一开始只是一根「实心棕柱」 | 体积遮罩用 `length(p.xz)`/`abs(p.y)`，而场以 **z 为轴** | 遮罩、条纹坐标、播种全部改回 `p.xy` / `p.z` |
| 看不出同心环 | 粒子在半径上连续均匀撒 | 撒在 **26 个离散壳**上（`r = rMax*(shell+0.5)/26`，±1.5% 抖动） |
| 跑几秒就糊成白团 | 这个场是**向轴收缩**的，示踪粒子迟早堆进核心 | 按注入式回收：寿命到、飞出域、或 `r < 5% rMax` 时重新撒回壳上 |
| 环发白、没有层次 | 12 万点加法混合过曝 | 每点 `a = core*(1-0.25*age)*0.05`，点径 3.2 px |
| 颜色全橙 | 早期按 |u| 着色（轴上最快） | 改**按半径**着色：`r/rMax<0.25` 白橙 → `<0.55` 橙 → 外圈蓝紫 |

对应旋钮（页面右侧）：体积密度、粒子数（2 万–30 万）、光柱随流强度、螺旋缠绕；相机默认 `pitch 0.42 / dist 3.6`（太平看不出环是圆的）。

实测（2217×1372 canvas）：**48–63 fps**（20 万粒子 + 体积 raymarch）。

## 13. 三项观感补齐（2026-11-01）

| 目标 | 做法 | 代价 |
| --- | --- | --- |
| **辉光（bloom）** | 场景先渲到离屏纹理 → 亮部提取（阈值 0.92 + knee）→ 1/2 分辨率分离高斯（横/纵各 9 tap）→ 加法合成；页面加「辉光强度」滑条 | 每帧多 4 个 pass，1280×820 下约 3 ms |
| **环更细更匀** | 环不再靠粒子撒点，改成**几何圆环层**：40 条等半径壳各 160 段 `gl.LINES`，颜色按半径取同一套调色板，加法混合 | 12800 个顶点，可忽略 |
| **柱的颗粒喷射** | 赤道盘/轴柱比例 78%/22%，轴柱粒子按真实 `u_z` 平流并按高度错开寿命，点径 3.2、单点 alpha 0.075；体积解析条纹降为辅助 | 无 |

新增 uniform/旋钮：`uAlpha`（环亮度 0.22）、`bloom`（0.45）、`bloomThresh`（0.92）、`ringAlpha`。
实测 **39–55 fps**（12 万粒子 + 体积 raymarch + 4 个后处理 pass，2217×1372 画布）。

## 14. 相机预设与外圈亮度（2026-11-01）

- **俯视环盘（`btn-top`）**：`yaw=-π/2, pitch=1.33, dist=2.55`。`pitch` 是仰角，视锥里环盘的短轴/长轴比 ≈ `sin(pitch)`：默认 0.62 时只有 0.58（椭圆），1.33 时 0.97（近似正圆）。这就是「参考图环是正圆、我们默认是椭圆」的全部原因，改的是机位不是数据。
- **侧视（`btn-side`）**：`pitch=0.10`，用来看轴向拉伸与上下收细的锥。
- **默认视角（`btn-reset`）**：`pitch=0.62, dist=3.1`（3/4 视角，兼顾环盘与柱体）。
- **外圈蓝紫层次**：该自相似场在 `r>0.35` 时 `Ω` 已经很低，再往外是纯几何壳、没有场强可依，所以环的颜色/亮度改为**按壳序号**给（`a = 0.55 + 0.95·r/rMax`，外圈更亮），不再依赖场强。实测俯视帧里蓝紫像素占比 31.6%、暖色 41.3%（此前外圈几乎不可见）。
- 截图：`docs/ns_vortex_top.png`（2217×1442，47 fps）。
