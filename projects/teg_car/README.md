## 模型

四域耦合，RK4 时间步进（`dt = 5 ms`，默认 48 001 步）：

| 域 | 方程要点 |
| --- | --- |
| 热 | 火焰对流 `q_in = h(T_flame − T_h)` 自限温；塞贝克/佩尔帖/焦耳热；冷端向环境散热 |
| 电 | 超级电容（决赛）或温差发电直驱（初赛）；欠压断流、限流、满电停止充电 |
| 机 | 电枢准静态（`L/R ≈ 1.4 ms ≪ dt`）、车轮与电机刚性啮合、滚阻 + 风阻 |
| 转向 | 凸轮轮廓 `δ(s)`（有限谐波拟合 + 转角标定）→ 自行车模型积分位姿 |

状态量 4 个（集总）或 `2n+2` 个（TEG 沿流向分 n 段）。

## 关键结论

- 化学能 → 电能只有 **0.07%**（138.7 kJ → 98.5 J），瓶颈在「火焰→板」的换热，不在 TEG 本身；
- 决赛 121.8 m / 初赛直驱 107.3 m（同一份参数）；
- 优化优先级：**减速比 > 散热能力 > 轻量化**；
- 绕桩净距仅 **+6 mm**，凸轮谐波阶数（≥8 阶）是唯一有效调节手段。

## 口径与限制（不要当成完整 CFD/FE 软件）

- 三维散热板：速度是**矩形通道充分发展层流**的泊肃叶解（Re 568），温度沿流向抛物型推进；
  **不是完整三维 N-S**（无回流、无湍流模型）；
- 底盘梁是 Euler-Bernoulli 梁单元，不是实体单元；
- 分段 TEG 只沿流向分段，段内仍均匀；
- 无热辐射项；电机用准静态效率，不含铁损/铜损随温度变化。
